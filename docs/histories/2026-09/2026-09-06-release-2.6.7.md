### 变更

- 将 `STKInfo.version` 从过期的 `2.0.0` 更新为 `2.6.7`。
- 将 Text Marker attribute 保留为等值字符串，避免引用新 SDK 常量破坏旧 SDK 编译。
- 将原生 AX 与 Text Marker 的取舍提取为内部决策 helper，并添加确定性回归测试。
- 不改动 README 中 Swift Package 的 `from: "2.0.0"` 兼容下限。
- 为发布建立执行计划，并在完成后归档。
